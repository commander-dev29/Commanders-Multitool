## Contributing
### Want to add a tool or improve the project?

1. Fork this repository.
2. Clone your fork.
3. Create a new branch for your changes. 
4. Make your changes and test them.
5. Push your branch to your fork.
6. Open a pull request to this repository.

All pull requests are reviewed before being merged.

### How to make a new tool
1. Create a new python file in the `Tools` folder.
2. Copy & paste the blank tool template located in `template.txt`
3. Start creating your tool!
4. *Optional: you can make your own libraries inside of the `Tools/Libraries/` folder to be used in tool modules.*
