## Core Information 
### Features
This Python application provides a modular and easy way to use and create tools! Some pre-included tools are as follows:
1. Random number generator
2. Password generator
3. QR code generator
4. File transfer tool *( WIP )*
5. Morse code translator *( WIP )*



## Contributing

Want to add a tool or improve the project?

1. Fork this repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Push your branch to your fork.
6. Open a pull request to this repository.

All pull requests are reviewed before being merged.
